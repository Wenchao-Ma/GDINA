# Simulated data (10 items, G-DINA model)

Simulated data, Q-matrix and item parameters for a 10-item test with 3
attributes.

## Usage

``` r
data(sim10GDINA)
```

## Format

A list with components:

- `simdat`:

  simulated responses of 1000 examinees

- `simQ`:

  artificial Q-matrix

- `simItempar`:

  artificial item parameters (probability of success for each latent
  group)

## References

Ma, W., & de la Torre, J. (2020). GDINA: An R Package for Cognitive
Diagnosis Modeling. *Journal of Statistical Software, 93(14)*, 1-26.
