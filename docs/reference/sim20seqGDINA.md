# Simulated data (20 items, sequential G-DINA model)

Simulated data, Qc-matrix and item parameters for a 20-item test
measuring 5 attributes.

## Usage

``` r
data(sim20seqGDINA)
```

## Format

A list with components:

- `simdat`:

  simulated polytomous responses of 2000 examinees

- `simQ`:

  artificial Qc-matrix

- `simItempar`:

  artificial item parameters (category level probability of success for
  each latent group)

## References

Ma, W., & de la Torre, J. (2020). GDINA: An R Package for Cognitive
Diagnosis Modeling. *Journal of Statistical Software, 93(14)*, 1-26.
