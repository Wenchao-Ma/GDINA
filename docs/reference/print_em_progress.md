# Print EM iteration progress

Prints iteration information with appropriate formatting.

## Usage

``` r
print_em_progress(itr, maxchg, neg2LL, verbose)
```

## Arguments

- itr:

  Iteration number

- maxchg:

  Maximum change

- neg2LL:

  Current deviance

- verbose:

  Verbosity level (1 = inline, 2 = newline)
