# Simulated data (10 items, MC-DINA model)

Simulated data, Q-matrix and item parameters for a 10-item test
measuring 3 attributes.

## Usage

``` r
data(sim10MCDINA)
```

## Format

A list with components:

- `simdat`:

  simulated responses of 3000 examinees

- `simQ`:

  artificial Q-matrix

## References

Ma, W., & de la Torre, J. (2020). GDINA: An R Package for Cognitive
Diagnosis Modeling. *Journal of Statistical Software, 93(14)*, 1-26.
