# Initialize solver arguments

Sets up default solver parameters for nloptr-based optimization.

## Usage

``` r
init_solver_args(auglag_args, solnp_args, nloptr_args)
```

## Arguments

- auglag_args:

  User-provided auglag arguments

- solnp_args:

  User-provided solnp arguments

- nloptr_args:

  User-provided nloptr arguments

## Value

List containing initialized solver arguments
